# mango-tools

这是一个个人使用的工具集，用来集中保存日常工作中需要的小工具和脚本。

## 组织方式

- 每个一级文件夹代表一个相对独立的工具。
- 每个工具在自己的目录中提供 `README.md`，说明用途、安装方法、启动方式和注意事项。
- 每个工具独立维护自己的版本号与变更记录；本仓库不设置统一版本号，也不要求所有工具同步发布。
- 依赖、测试、启动入口和运行说明尽量放在对应工具目录内。
- 根目录只维护工具索引和通用仓库规则，不承载具体工具的详细文档。

| --- | --- |

## 新增工具

新增工具时创建独立的一级目录，并在目录中至少提供一个 `README.md`。只有多个工具已经产生稳定的共享需求时，才考虑增加公共模块。
