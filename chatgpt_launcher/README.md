# ChatGPT 连接助手

版本：1.3.1（2026-11-12）。Windows 原生托盘启动器，无第三方运行库，不是 ChatGPT 客户端或 VPN。

## 使用

1. 运行 `dist/ChatGPT-Connection-Helper.exe`。
2. 程序尝试定位 Microsoft Store 安装的 OpenAI.Codex / OpenAI.ChatGPT；找不到时选择原版 `ChatGPT.exe`。其他布局需手动选择，不保证所有发行版适用。
3. 备用代理优先读取 Windows 系统代理地址，否则填入 `http://127.0.0.1:7890`；可修改为本机 VPN 实际的 **HTTP** 代理地址。仅支持无用户名密码的 HTTP CONNECT 代理，不支持 SOCKS 和 PAC 自动解析。
4. 点击“检测并启动 ChatGPT”。应用运行中会询问是否重启，先正常退出，8 秒后仍在运行才询问是否强制退出。拒绝强制退出时可从应用托盘手动退出再试。
5. 关闭助手窗口会从任务栏消失，仅保留右下角托盘（可能在 Windows 的隐藏图标区域），双击可打开；右键退出助手不会关闭 ChatGPT。再次运行 EXE 会打开同一助手窗口。

助手使用原版 ChatGPT 图形，不加字母或白色底圈；绿色小圆点表示默认启动，蓝色小圆点表示指定代理，无圆点表示未识别或已退出。悬停查看文字模式。右键托盘选择“退出助手（保留 ChatGPT）”可彻底关闭助手及托盘图标。助手打开后会只读识别运行中应用的代理环境变量；优先读取有主窗口的进程，否则读取同路径最早启动的进程。不需要重新启动 ChatGPT，也能识别原入口或旧脚本启动的应用。图标表示进程中的显式代理配置，**不代表实时网络状态**；默认模式仍可能走系统代理或 TUN。权限不同或进程信息无法读取时显示“模式无法读取”，不会猜测。应用重启或退出后会自动更新。不会保存环境块或代理值。ChatGPT 保留其自身原版图标；本助手不修改它的任务栏身份。

## 自动选择的准确边界

默认路径探测不指定 HTTP 代理，但可能被 VPN 的 TUN 接管。对 ChatGPT Responses 地址发起不带登录凭据的 WebSocket Upgrade 请求：101、401、426 记为路径可达；403、重定向、其他状态或连接错误记为未通过。默认路径未通过才检测指定代理。两者均失败则不退出或重启现有应用。

**401/426 不等于已登录 WebSocket 成功**。这是保守的启动前路由探测，不能验证账号、模型请求或长连接稳定性；服务器行为变化可能导致误判。助手不会读取令牌或关闭 TLS 证书校验。自动选择不合适时，可以选“仅指定代理”或“仅默认路径”再检测启动；不会在使用过程中自动重启。

默认启动清除子进程环境中的 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY、WS_PROXY、WSS_PROXY、NO_PROXY；系统代理仍可能生效。指定代理仅向新启动的进程及子进程注入 HTTP_PROXY、HTTPS_PROXY、NO_PROXY，不改用户/系统环境变量，不启动或关闭 VPN。启动助手时应用已存在的旧环境不能被原地修改，因此需要重启。

永久指定 7890 的局限：代理程序没启动、换端口、换电脑后会连接失败；如果代理程序仍监听但 VPN 节点不可用，也可能失败。检测会向 chatgpt.com 发出无凭据请求。当前窗口内修改的地址和路径不写入系统，退出助手后重新检测。

## 构建与携带

适用 Windows 10/11，需 .NET Framework 4.7.2 或更高版本、Windows PowerShell 5.1。在工具目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本使用系统自带 .NET Framework C# 编译器，编译为 AnyCPU EXE 并执行自检。将 `dist` 中的 EXE 复制到其他兼容 Windows 电脑即可运行；无需复制本仓库、安装 Python 或开发工具。应用本体和 VPN 需另行安装。EXE 未签名，Windows 可能显示未知发布者提示。

`tests.ps1` 验证子进程继承、默认模式清理和离线探测分类；加 `-Network` 可做真实的未登录网络探测，不启动或退出 ChatGPT。

## 目录

- `src/`：启动器源码。
- `assets/`：原版应用图标及资源来源说明。
- `tests/`：自动检查和界面预览检查。
- `docs/`：产品与界面说明。
- `dist/`：可携带的程序和使用说明（生成文件，不提交 Git）。
- `work/`：测试程序、预览图（生成文件，不提交 Git）。
- `build.ps1` / `tests.ps1`：构建与测试入口。
