# ChatGPT 连接助手

自动选择默认连接或本地代理，减少 ChatGPT 桌面版反复重连的等待。**这是免安装的小工具，不是 ChatGPT 本体，也不是 VPN。**

程序版本：1.3.1。适用 Windows 10/11；电脑需有 .NET Framework 4.7.2 或更高版本，以及 Windows PowerShell 5.1。一般无需额外安装开发工具。

## 第一次使用：按你拿到的文件选择

### 已经拿到 EXE 或便携包（推荐）

1. 如果是 ZIP 压缩包，先右键“全部解压”，不要直接在压缩包内运行。
2. 把 **`ChatGPT-Connection-Helper.exe` 复制到桌面**或你喜欢的文件夹。
3. 双击 EXE，按下文“日常使用”操作。

**只需要这一个 EXE。** 不需要源码、资源文件夹、Git、Python 或编译工具，也不需要保留原来的仓库文件夹。说明文档可以保留方便查阅，但程序运行不依赖它。

### 从本仓库下载，找不到 EXE

**仓库保存的是源码，不包含 EXE；`dist` 是准备完成后才出现的文件夹。** 不用输入命令：

1. 下载仓库 ZIP 并完整解压，或者打开已经下载好的仓库。
2. 进入 **`chatgpt_launcher`** 文件夹，双击 **`prepare.cmd`**。
3. 等待准备完成。它会自动打开 `dist` 文件夹，把里面的 **`ChatGPT-Connection-Helper.exe` 复制到桌面**即可使用。

准备操作只在第一次或需要更新时执行，平时直接双击 EXE。请勿只下载 `prepare.cmd`，它需要解压后的完整工具文件夹。

如果准备失败，窗口会保留错误信息，不会启动应用。若旧助手正在运行，先从托盘右键退出助手，再双击 `prepare.cmd`；**ChatGPT 本体不用关闭**。

## 日常使用

1. 如果上网需要 VPN，先按平时的方式开启 VPN。
2. 双击桌面上的连接助手。
3. 如果 ChatGPT 已经运行，助手会自动识别并显示当前模式，**查看模式不需要重启**。
4. 需要启动或切换连接时，保留“自动选择”，点击 **“检测并启动 ChatGPT”**或“重新检测并重启 ChatGPT”。
5. ChatGPT 已经运行时会先询问是否重启。等任务结束、保存输入后再确认；不确认就不会切换。

助手会先检测默认路径，不通过再检测备用代理。两条路径都失败时保留原来的应用，不会把它关掉。自动选择不合适时，可以手动选“仅使用默认连接”或“仅使用指定代理”。

第一次没找到 ChatGPT：点击“更改…”选择本机已安装的原版 `ChatGPT.exe`。助手不包含、也不会安装 ChatGPT。

代理地址通常会自动填写；如果你的 VPN 用的不是这个地址，请在 VPN 客户端查看 **HTTP 代理地址/端口**，填入例如 `http://127.0.0.1:7890`。不要把另一台电脑的端口照搬过来。仅支持无账号密码的 HTTP 代理；不支持 SOCKS 或 PAC 自动解析。手动填写的路径和地址只在当前助手窗口内保留，退出助手后重新检测。

## 关窗口、查看模式和完全退出

| 操作 / 图标 | 结果 |
| --- | --- |
| 点击窗口右上角 × | 隐藏助手窗口，从任务栏消失，仅保留右下角托盘图标 |
| 找不到托盘图标 | 点击 Windows 右下角的“显示隐藏的图标”箭头 |
| 双击托盘图标 | 重新打开助手窗口 |
| 鼠标悬停在托盘图标上 | 显示当前模式的文字说明 |
| 绿色小圆点 | 默认连接配置 |
| 蓝色小圆点 | 指定代理配置 |
| 无圆点 | 尚未识别、无法读取，或 ChatGPT 未运行；打开窗口查看原因 |
| 右键托盘 → “退出助手（保留 ChatGPT）” | 完全关闭助手和托盘图标，不关闭 ChatGPT |

图标反映的是应用的代理配置，**不是实时网络质量指示灯**。默认模式仍可能受系统代理或 VPN 接管影响。

## 能不能直接拖到桌面？

**可以。推荐“复制 EXE 到桌面”，最不容易弄混。**

- **复制或移动 EXE 本体**：桌面上是一份可独立运行的程序。原仓库移动或删除后，它仍能使用。
- **创建快捷方式**：桌面上只是指向原文件的入口。原 EXE 被移动或删除后，快捷方式会失效。
- 直接拖拽有时是移动、有时是复制，取决于磁盘位置。想确定保留原文件，使用“复制 → 粘贴”；想创建快捷方式，右键 EXE →“显示更多选项”（如有）→“发送到 → 桌面快捷方式”。

右键桌面入口 →“属性”：如果有“快捷方式”选项卡和“目标”字段，它就是快捷方式。若目标位于仓库的 `chatgpt_launcher/dist` 文件夹，使用时仍依赖这个位置。要彻底独立于仓库，复制 EXE 本体到桌面，并使用这份 EXE。

## 在另一台 Windows 电脑上使用

1. 在另一台电脑先安装、登录原版 ChatGPT；如果需要 VPN，也先装好并连接。
2. 把 **EXE 本体**用 U 盘或其他方式复制到那台电脑的桌面。**不要复制 `.lnk` 快捷方式**，它不能代替程序。
3. 双击助手。它会重新查找那台电脑上的 ChatGPT 和系统代理，不依赖原电脑的用户名或仓库路径。
4. 点击“检测并启动 ChatGPT”；只有未找到应用或代理地址不匹配时，才需要手动更改。

如果你只有源码仓库而没有 EXE，按前面的“从本仓库下载”步骤双击 `prepare.cmd` 即可准备程序。

EXE 尚未签名，Windows 可能提示未知发布者。请先确认文件来自你信任的来源；公司电脑若禁止运行，请联系管理员，不要关闭安全软件。

## 如何更新

**下载或拉取新源码，不会自动更新正在使用的程序。**

1. 托盘右键退出连接助手，ChatGPT 和 VPN 可以继续运行。
2. 拿到新的 EXE；如果拿到的是新源码，双击其中的 `prepare.cmd`，等待文件夹打开。
3. 用新 EXE 替换你平时双击的那一份，再重新打开。

如果平时运行的是桌面上的 EXE 副本，就替换桌面那份；如果用的是快捷方式，就替换它“目标”指向的 EXE。程序没有自动更新功能，也不会自动更新其他位置的副本。

## 常见问题

- **打开第二份助手却没看到新窗口？** 同一登录会话只运行一个助手；重复打开会唤起原来的窗口。替换或测试另一份程序前，请先从托盘退出旧助手。
- **关 VPN 后不能联网？** 代理模式仍指向 VPN 的本地入口。重新打开助手并检测、切换；默认模式能否连接，仍取决于当前网络是否能访问 ChatGPT。
- **为何检测通过后仍会失败？** 检测不使用登录凭据，只判断连接路径；不能保证账号、模型请求和长连接都正常。
- **显示“模式无法读取”？** 可能是助手与 ChatGPT 权限不同，或应用正在退出；不会因此强制重启。尽量以同一普通用户运行两者。
